# Icônes du HUD

Six sprites RGBA natifs de 32 × 32 px, transparence binaire, 3 à 7 couleurs opaques. Affichage sans lissage ; les touches I/G restent du texte accessible superposé aux boutons.

- `bag.png` : sac de cuir.
- `companions.png` : deux aventuriers.
- `sound.png` : cor médiéval ; la barre de coupure est rendue par le bouton.
- `coins.png` : monnaie.
- `guild.png` : bannière de fondation.
- `close.png` : fermeture.

Créés pour ce fork avec génération des trois sujets principaux, extraction de leur grille native et contrôle visuel en jeu. Les sources et planches de contrôle locales sont conservées dans `output/hud-icons/` (hors Git). Les sprites livrés passent le contrôle 32 × 32, palette de huit couleurs au maximum et alpha 0/255.
